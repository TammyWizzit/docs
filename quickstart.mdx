This quickstart walks you through everything you need to get productive with Wizzit fast. By the end, you'll have a verified account, a live API key, your first document created via the REST API, and a clear path to connecting your first integration — all in under ten minutes.

## Prerequisites

Before you begin, make sure you have the following:

- A Wizzit account — sign up for free at [app.wizzit.com](https://app.wizzit.com)
- An API key generated from your Wizzit dashboard (see Step 2 below)
- `curl` installed on your machine, or any HTTP client you prefer

## Steps

<Steps>
  <Step title="Create Your Account">
    Head to [app.wizzit.com](https://app.wizzit.com) and complete the sign-up form. Wizzit will send you a verification email — click the link inside to activate your account and access your workspace for the first time.
  </Step>
  <Step title="Generate an API Key">
    Once you're logged in, navigate to **Settings → API Keys** and click **Create New Key**. Give your key a descriptive name (for example, `quickstart-key`) and copy the value shown — you won't be able to view it again after closing the dialog.

    Store your API key somewhere safe, such as an environment variable or a secrets manager. You'll use it in every request to the Wizzit API.
  </Step>
  <Step title="Create Your First Document">
    With your API key in hand, create your first document by sending a `POST` request to the Wizzit API:

    ```bash
    curl -X POST https://api.wizzit.com/v1/documents \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "title": "My First Document",
        "content": "Hello, Wizzit!",
        "visibility": "private"
      }'
    ```

    A successful response returns a `201 Created` status along with the new document object, including its unique `id`. Copy that `id` — you'll use it in the next step.
  </Step>
  <Step title="Retrieve the Document">
    Confirm your document was created by fetching it directly using its `id`:

    ```bash
    curl -X GET https://api.wizzit.com/v1/documents/{id} \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    Replace `{id}` with the document ID returned in the previous step. The response includes the full document object with its title, content, visibility setting, and metadata.
  </Step>
  <Step title="Connect an Integration">
    Now that your first document is live, you're ready to connect Wizzit to the tools your team uses every day. Head over to the [Integrations](/integrations/overview) section to browse the available connectors and follow the setup guide for your chosen system.
  </Step>
</Steps>

<Tip>
  Looking for a more powerful programmatic experience? The [Wizzit SDK](/sdk/overview) wraps the REST API in idiomatic client libraries, handles authentication for you, and includes helpers for batch operations, webhooks, and more.
</Tip>
