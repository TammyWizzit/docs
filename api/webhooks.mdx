Webhooks let you receive real-time HTTP notifications when events happen in your Wizzit workspace — such as a document being created, updated, or shared with a client. You register a webhook by providing an HTTPS endpoint URL and a list of event types you want to subscribe to. Wizzit will deliver a signed JSON payload to your endpoint each time a matching event occurs.

For details on the delivery payload format and how to verify the webhook signature using your secret, see the [Webhooks integration guide](/integrations/webhooks).

---

## GET /webhooks

Retrieve a list of all webhook endpoints registered in your workspace.

### Query Parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page. Maximum is `100`.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Example Response

```json
{
  "success": true,
  "data": [
    {
      "id": "wh_01hxbs7qp2",
      "url": "https://myapp.example.com/webhooks/wizzit",
      "events": ["document.created", "document.shared"],
      "status": "active",
      "created_at": "2024-04-05T08:00:00Z",
      "updated_at": "2024-04-05T08:00:00Z"
    }
  ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 1
  }
}
```

## POST /webhooks

Register a new webhook endpoint. Wizzit will begin delivering event payloads to the specified URL immediately after creation.

### Request Body

<ParamField body="url" type="string" required>
  The HTTPS URL of your endpoint. Wizzit will send `POST` requests to this URL when a subscribed event occurs. Must use `https://`.
</ParamField>

<ParamField body="events" type="array" required>
  An array of event type strings to subscribe to. Accepted values: `document.created`, `document.updated`, `document.deleted`, `document.shared`, `user.invited`, `integration.created`, `integration.disabled`.
</ParamField>

<ParamField body="secret" type="string" required>
  A secret string used to sign webhook payloads. Wizzit includes a signature in the `X-Wizzit-Signature` header of every delivery so you can verify the payload came from Wizzit. Store this securely.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/webhooks \
  -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://myapp.example.com/webhooks/wizzit",
    "events": ["document.created", "document.shared"],
    "secret": "my_webhook_secret_abc"
  }'
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "wh_01hxbs7qp2",
    "url": "https://myapp.example.com/webhooks/wizzit",
    "events": ["document.created", "document.shared"],
    "status": "active",
    "created_at": "2024-05-22T12:00:00Z",
    "updated_at": "2024-05-22T12:00:00Z"
  }
}
```

Returns `201 Created` on success. The `secret` is never included in the response after creation.

## GET /webhooks/{id}

Retrieve the configuration and delivery statistics for a specific webhook.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook (e.g., `wh_01hxbs7qp2`).
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/webhooks/wh_01hxbs7qp2 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "wh_01hxbs7qp2",
    "url": "https://myapp.example.com/webhooks/wizzit",
    "events": ["document.created", "document.shared"],
    "status": "active",
    "delivery_stats": {
      "total": 148,
      "successful": 145,
      "failed": 3,
      "last_delivery_at": "2024-05-22T11:55:00Z"
    },
    "created_at": "2024-04-05T08:00:00Z",
    "updated_at": "2024-04-05T08:00:00Z"
  }
}
```

### Response Fields

<ResponseField name="id" type="string">
  The unique identifier of the webhook.
</ResponseField>

<ResponseField name="url" type="string">
  The registered endpoint URL.
</ResponseField>

<ResponseField name="events" type="array">
  The list of event types this webhook is subscribed to.
</ResponseField>

<ResponseField name="status" type="string">
  Whether the webhook is `active` or `disabled`.
</ResponseField>

<ResponseField name="delivery_stats" type="object">
  An object summarising delivery performance: `total`, `successful`, `failed`, and `last_delivery_at`.
</ResponseField>

## PATCH /webhooks/{id}

Update a webhook's URL, subscribed events, or status. Only the fields you include in the request body are changed.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to update.
</ParamField>

### Request Body

<ParamField body="url" type="string">
  Updated endpoint URL. Must use `https://`.
</ParamField>

<ParamField body="events" type="array">
  Updated list of event types to subscribe to. Replaces the existing list entirely.
</ParamField>

<ParamField body="status" type="string">
  Set to `active` or `disabled` to enable or pause deliveries.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/webhooks/wh_01hxbs7qp2 \
  -X PATCH \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "events": ["document.created", "document.updated", "document.shared"]
  }'
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "wh_01hxbs7qp2",
    "url": "https://myapp.example.com/webhooks/wizzit",
    "events": ["document.created", "document.updated", "document.shared"],
    "status": "active",
    "created_at": "2024-04-05T08:00:00Z",
    "updated_at": "2024-05-22T13:45:00Z"
  }
}
```

## DELETE /webhooks/{id}

Remove a webhook endpoint. Wizzit will immediately stop delivering events to the associated URL.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to remove.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/webhooks/wh_01hxbs7qp2 \
  -X DELETE \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

Returns `204 No Content` with an empty body on success.
