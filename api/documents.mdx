Documents are the core resource in Wizzit. Each document belongs to a workspace and can be internal (visible only to your team) or shared with external clients. The Documents API lets you create and manage documents programmatically — whether you're automating publishing workflows, syncing content from external sources, or building a custom document portal for your clients.

---

## GET /documents

Retrieve a paginated list of documents in your workspace. You can filter by type, visibility, and tag.

### Query Parameters

<ParamField query="type" type="string">
  Filter by document type. Accepted values: `page`, `file`, `template`.
</ParamField>

<ParamField query="visibility" type="string">
  Filter by visibility setting. Accepted values: `private`, `internal`, `public`.
</ParamField>

<ParamField query="tag" type="string">
  Filter documents that include a specific tag (exact match).
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to retrieve.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page. Maximum is `100`.
</ParamField>

### Example Request

```bash
curl "https://api.wizzit.com/v1/documents?visibility=internal&limit=5" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Example Response

```json
{
  "success": true,
  "data": [
    {
      "id": "doc_01hx4k2mz9",
      "title": "Onboarding Guide",
      "type": "page",
      "visibility": "internal",
      "tags": ["hr", "onboarding"],
      "created_at": "2024-03-15T09:22:00Z",
      "updated_at": "2024-04-01T14:05:00Z"
    },
    {
      "id": "doc_01hx4k9pq7",
      "title": "Security Policy",
      "type": "page",
      "visibility": "internal",
      "tags": ["compliance"],
      "created_at": "2024-02-10T11:00:00Z",
      "updated_at": "2024-02-10T11:00:00Z"
    }
  ],
  "meta": {
    "page": 1,
    "per_page": 5,
    "total": 42
  }
}
```

## POST /documents

Create a new document in your workspace.

### Request Body

<ParamField body="title" type="string" required>
  The title of the document. Must be between 1 and 255 characters.
</ParamField>

<ParamField body="content" type="string">
  The body content of the document in Markdown format.
</ParamField>

<ParamField body="type" type="string" default="page">
  The document type. Accepted values: `page`, `file`, `template`.
</ParamField>

<ParamField body="visibility" type="string" default="private">
  Who can access the document. Accepted values: `private`, `internal`, `public`.
</ParamField>

<ParamField body="tags" type="array">
  An array of tag strings to categorise the document (e.g., `["hr", "policy"]`).
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/documents \
  -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Client Onboarding Checklist",
    "content": "## Welcome\n\nUse this checklist to complete onboarding.",
    "type": "page",
    "visibility": "internal",
    "tags": ["onboarding", "client"]
  }'
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "doc_01hx5m3rw2",
    "title": "Client Onboarding Checklist",
    "content": "## Welcome\n\nUse this checklist to complete onboarding.",
    "type": "page",
    "visibility": "internal",
    "tags": ["onboarding", "client"],
    "created_at": "2024-05-20T08:30:00Z",
    "updated_at": "2024-05-20T08:30:00Z"
  }
}
```

Returns `201 Created` on success.

## GET /documents/{id}

Retrieve a single document by its ID.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the document (e.g., `doc_01hx5m3rw2`).
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/documents/doc_01hx5m3rw2 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "doc_01hx5m3rw2",
    "title": "Client Onboarding Checklist",
    "content": "## Welcome\n\nUse this checklist to complete onboarding.",
    "type": "page",
    "visibility": "internal",
    "tags": ["onboarding", "client"],
    "created_at": "2024-05-20T08:30:00Z",
    "updated_at": "2024-05-20T08:30:00Z"
  }
}
```

### Response Fields

<ResponseField name="id" type="string">
  The unique identifier of the document.
</ResponseField>

<ResponseField name="title" type="string">
  The document title.
</ResponseField>

<ResponseField name="content" type="string">
  The document body content in Markdown format.
</ResponseField>

<ResponseField name="type" type="string">
  The document type: `page`, `file`, or `template`.
</ResponseField>

<ResponseField name="visibility" type="string">
  The visibility setting: `private`, `internal`, or `public`.
</ResponseField>

<ResponseField name="tags" type="array">
  List of tags associated with the document.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the document was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update.
</ResponseField>

## PUT /documents/{id}

Fully replace a document's fields. All writable fields are overwritten with the values you provide — any field not included in the request body is reset to its default value.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the document to update.
</ParamField>

### Request Body

<ParamField body="title" type="string" required>
  The updated document title.
</ParamField>

<ParamField body="content" type="string">
  The updated body content in Markdown format.
</ParamField>

<ParamField body="type" type="string">
  The updated document type: `page`, `file`, or `template`.
</ParamField>

<ParamField body="visibility" type="string">
  The updated visibility: `private`, `internal`, or `public`.
</ParamField>

<ParamField body="tags" type="array">
  The updated list of tags. Replaces the existing tag list entirely.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/documents/doc_01hx5m3rw2 \
  -X PUT \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Client Onboarding Checklist (Updated)",
    "content": "## Welcome\n\nRevised checklist for Q3.",
    "type": "page",
    "visibility": "public",
    "tags": ["onboarding"]
  }'
```

### Example Response

```json
{
  "success": true,
  "data": {
    "id": "doc_01hx5m3rw2",
    "title": "Client Onboarding Checklist (Updated)",
    "content": "## Welcome\n\nRevised checklist for Q3.",
    "type": "page",
    "visibility": "public",
    "tags": ["onboarding"],
    "created_at": "2024-05-20T08:30:00Z",
    "updated_at": "2024-05-21T10:15:00Z"
  }
}
```

## DELETE /documents/{id}

Permanently delete a document from your workspace. This action cannot be undone.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the document to delete.
</ParamField>

### Example Request

```bash
curl https://api.wizzit.com/v1/documents/doc_01hx5m3rw2 \
  -X DELETE \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

Returns `204 No Content` with an empty body on success.
